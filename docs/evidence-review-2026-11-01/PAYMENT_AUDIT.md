# 支付稽核與來源凍結

記錄日期：2026-11-01
狀態：待補原始稽核及當時來源；本文不是原稽核的復原。

## 目前缺件
- 原始支付稽核全文、完成日期與逐條結論。
- 每條結論引用的官方規格 URL、章節與版本。
- 當時保存的原始內容及取得時間。
- 原始檔 SHA-256、覆核者與覆核範圍。

未取得不等於不存在。
補齊前，不將先前結論當成已具備可重查來源的稽核結果。

## 每個來源應保存
規格名稱、發布機構、原始與實際取得 URL、
版本或 release tag、文件標示日期、
取得時間與時區、保存檔路徑與格式、
原始 bytes 的 SHA-256、引用章節、
支援的稽核主張、覆核者與覆核日期。

## 保存與重用規則
保留完整原始檔。
文字擷取、翻譯與整理另存衍生檔並記錄轉換方式。
原始與衍生檔各自計算雜湊，不互相替代。

如果只能取得今日網頁，記為新取得版本，
不得回填成當時稽核使用的版本。
重新取得的版本必須逐條重審後才能支援新結論。

雜湊可比較內容，但不能單獨證明發布者或取得時間。
沒有當時原始內容，就不填造歷史雜湊。

本次不新增清算功能、程式、fixture 或 DF 編號。
