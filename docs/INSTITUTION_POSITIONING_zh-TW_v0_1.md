# 機構溝通定位 v0.1

狀態：溝通文字定稿；正式名稱待商標查詢後確定。
核對基準：7e2c540。本文不取代或擴張 CLAIMS_STATUS.md。

## 定位

協助檢查安全主張背後的證據是否足夠，並指出缺口。

| 安全問題 | 目前可協助檢查的範圍 |
|---|---|
| AI 內容被採用或替換後，紀錄是否仍對得上？ | 檢查原始輸出、版本與採用內容的連結 |
| 「已覆核」有哪些紀錄支持？ | 檢查覆核者、覆核段落，以及產出與來源的版本、內容綁定；目前不檢查時間 |
| 來源後來改變，能否辨識？ | 比對來源當時的版本與內容，不只看網址 |
| 多份紀錄是否一致？ | 辨識版本或內容不一致；目前尚無法判斷來源是否獨立 |
| 證據不足時如何處理？ | 標示為「無法確認」，不把缺漏視為通過 |

PHAGE Evidence Engine 是研究原型，目前能力驗證以既有合成案例與檢查器範圍為限，尚未完成真實機構紀錄的外部驗證。
